This project is a localized, SQLite-based Hospital Bed Allocation System built to solve common resource management challenges in healthcare facilities. It provides a structured relational database solution for streamlining the patient admission lifecycle, tracking real-time bed availability across specialized wards, and managing patient records. Developed to showcase core database management skills, the project features a well-defined schema and optimized queries for daily operations. It effectively illustrates how data management can improve administrative efficiency and ensure smooth operational flow within a medical center.
